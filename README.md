Proyecto en construccion para el Curso de React Js.

  Se basa en una tienda/E-comerce de productos varios.

  Hasta el momento el funcionamiento:
    -Carga un listado de productos, los mismos se pueden ir agregando al carrito o eliminar. 
    -Como no hay persistencia de datos, al actualizar o navegar por la pagina, se pierden los productos en Carrito.
